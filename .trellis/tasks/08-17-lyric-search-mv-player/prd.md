# 歌词搜索与 MV 内置播放器

## 目标

在播放详情页提供可编辑歌名、按歌曲信息排序并可立即应用的歌词查找体验；同时为当前歌曲提供应用内 MV 播放入口，并允许用户在设置中选择已集成的视频播放引擎，避免调用车机系统播放器。

## 已确认现状

- 播放详情歌词工具栏已经有搜索入口，`SearchLrc` 面板会以当前歌曲别名或歌名自动搜索，输入框也可编辑。
- 现有歌词结果按音源拆成 Tab；结果项只显示歌名、歌手、音源和封面，没有专辑字段，也没有跨音源统一相关性排序。
- `lyricManager.associateLyric` 已能把点选结果关联到当前歌曲并刷新歌词，可作为新列表的应用边界。
- 项目还保留一个输入 MusicFree 内部媒体 ID 的 `AssociateLrc` 面板；本需求将移除该入口，歌词查找不再依赖内部 ID。
- 插件协议当前只有 `search(..., "lyric")`、`getLyric` 和音频 `getMediaSource`，没有 MV 查询或视频源返回契约。
- 线上 `1.js` 至 `9.js` 当前都未实现 MV 方法；Bilibili 音源项目本身带 `bvid` 视频身份，其余音源需要按各平台歌曲信息查询 MV。
- Android 当前最低版本为 API 24，React Native 为 0.76.5；工程没有视频播放器依赖。本任务允许把最低版本提升到 API 26，以直接集成 libmpv AAR。最终界面需要继续适配 1920x1080 车机横屏和现有车机字号档位。

## 需求

### R1. 歌词查找

- 播放详情歌词栏保留一个始终可访问的“查找歌词”入口，不论当前是否已有歌词。
- 打开后默认填入当前歌曲别名或歌名，用户可编辑并重新搜索。
- 查询所有已启用且支持歌词搜索的音源，将结果合并为一个列表，而不是要求用户逐个切换音源 Tab。
- 每项至少展示歌名、歌手、专辑、来源平台和可用封面。
- 结果按与当前查询及当前歌曲信息的相关性从高到低稳定排序；相同分数保持音源顺序和原始结果顺序。
- 点选结果后必须先取得有效歌词，再关联到当前播放歌曲并立即刷新；失败时保留原歌词和原关联。
- 删除面向用户的“输入内部媒体 ID 关联歌词”入口；已有歌词关联数据继续兼容读取和解除。

### R2. MV 能力与入口

- 播放详情页增加 MV 按钮；只有当前音源能返回可播放 MV 时才进入播放，否则显示明确的不可用提示。
- 扩展插件能力，让对应音源按当前歌曲查询 MV，并返回应用内播放器可消费的视频地址、必要请求头和可选清晰度信息。
- MV 只由当前歌曲所属音源查询和返回；当前平台没有 MV 时提示不可用，不跨平台搜索或猜测同名视频。
- 在当前仓库中交付更新后的 `1.js` 至 `9.js` 替换文件；用户负责在验收后上传到现有 `/yuan/` 在线地址。
- 打开 MV 时暂停当前音频；退出后仅在原歌曲仍是当前歌曲且进入前正在播放时恢复音频，避免音频与视频叠加或恢复错误歌曲。

### R3. 应用内视频播放

- 视频在 MusicFree 内部页面播放，不调用 Android 文件选择器、系统播放器或外部浏览器。
- 首版同时集成 ExoPlayer 与 MPV，默认使用 ExoPlayer；MPV 作为用户可选的兼容引擎。
- 不集成 IJKPlayer；它与 MPV 的能力重复，且当前正式依赖和 React Native 适配风险明显更高。
- Android 最低版本从 API 24 提升到 API 26；Android 7 设备不再属于新包兼容范围。
- 支持播放/暂停、进度拖动、时长、全屏横屏、返回退出、加载中、失败重试和必要的请求头。
- 播放页提供 MV 清晰度菜单，默认选择不高于 1080p 的最高可用档位，并持久化最近选择。
- 当前清晰度播放失败时按插件返回的清晰度顺序自动降一级重试；全部失败后保留错误页和手动重试入口。
- 全部清晰度失败后允许用另一个已集成引擎重试当前会话，但不自动改写用户持久化的默认播放器。
- 设置页新增“默认 MV 播放器”选项，只展示实际随 APK 集成且当前设备可用的引擎。
- 新增播放器不能破坏现有音频播放、后台通知、歌词、车机模式和备份配置。

## 验收标准

- [ ] 从播放歌词栏打开查找面板时默认歌名正确且可编辑；修改后能发起新搜索。
- [ ] 多个歌词音源的候选出现在同一列表，展示歌名、歌手、专辑、来源和封面，并按相关性从高到低排列。
- [ ] 点选有效候选后当前歌曲立即显示所选歌词；候选无歌词或请求失败时原歌词不变。
- [ ] 有 MV 的当前歌曲可从播放页进入 MusicFree 内部视频页；无 MV 时不会误开外部播放器。
- [ ] MV 播放覆盖播放/暂停、拖动、全屏、返回、失败重试，并且不会与当前音频叠加播放。
- [ ] 设置中可切换所有已集成引擎，重启后保持选择；不可用引擎有稳定回退或明确提示。
- [ ] 至少对一个普通音乐平台和 Bilibili 音源完成真实 MV 播放验证。
- [ ] 仓库交付的 `1.js` 至 `9.js` 均可被 MusicFree 解析和导入；有 MV 的样本返回符合新契约的地址和清晰度，无 MV 的样本稳定返回空结果。
- [ ] TypeScript、歌词排序/关联测试、插件 MV 契约测试、Android 编译及 1920x1080 车机横屏验证通过。
- [ ] 最终 APK manifest 的最低版本为 API 26，Android 8 及当前车机环境可以安装并启动。

## 范围外

- 不调用系统播放器或外部浏览器播放 MV。
- 不实现 MV 下载、弹幕、评论、投屏或后台画中画。
- 不把视频播放引擎用于替换现有音频 TrackPlayer。
- 不在本任务中迁移旧版 MusicFree 数据。
- 不继续支持 Android 7 及以下系统。
- 不直接上传或覆盖 `23.254.235.247` 上的在线音源文件。
- 本次 MV 原生播放器只支持 Android；不宣称 iOS 已实现 MPV。
