# 播放详情歌手专辑跳转搜索

## Goal

从播放详情的歌曲信息面板直接查找当前歌手或专辑的相关结果，减少返回首页后
重新输入和切换分类的操作。

## Requirements

- 点击歌手行关闭当前面板，打开搜索页，以歌手名自动执行“单曲”搜索。
- 点击专辑行关闭当前面板，打开搜索页，以专辑名自动执行“单曲”搜索。
- 插件切换和翻页继续使用路由带入的关键词。
- 歌手或专辑为空时不展示对应可点击入口。
- ID、播放、下载、歌词关联等其他歌曲选项保持原行为。

## Acceptance Criteria

- [ ] 歌手点击后的搜索框关键词正确，选中分类和请求类型均为单曲。
- [ ] 专辑点击后的搜索框关键词正确，选中分类和请求类型均为单曲。
- [ ] 从搜索结果继续打开歌手/专辑详情的现有行为不变。
- [ ] 手动从首页进入搜索页时仍为空白编辑状态。

## Out Of Scope

- 不根据歌曲字符串伪造歌手或专辑详情对象，也不绕过插件搜索接口。
- 本次不保留歌手/专辑行原有的单击复制行为。
