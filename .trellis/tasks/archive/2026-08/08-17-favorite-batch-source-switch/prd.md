# 收藏歌曲批量换源

## Goal

当收藏歌曲原音源失效时，允许用户勾选或全选歌曲，并将可确认匹配且可播放的
歌曲迁移到指定的另一个插件来源。

## Requirements

- 收藏歌单菜单新增“批量换源”，进入复用现有勾选列表的专用模式。
- 专用模式支持单选、多选和全选，不提供无关的排序、删除或下载操作。
- 目标列表仅包含已启用且支持单曲搜索的插件，并标明当前选择。
- 每首歌曲在目标插件内搜索；匹配必须综合标准化标题、歌手，并用时长/专辑作
  辅助判定，不能只取搜索第一项。
- `platform@id` 只用于来源内部身份和去重，绝不把不同平台的 ID 作为同曲依据。
- 原曲、现场版、Remix、伴奏、纯音乐、翻唱和 DJ 版等版本标记必须兼容；
  无法确认是同一录音版本时判定为匹配失败。
- 候选项必须能通过插件取流或自带有效 URL，验证成功后才替换。
- 成功替换时更新歌曲的 `id`、`platform` 及目标源元数据，保持原歌单位置；
  不把临时验证 URL 当作长期可用地址持久化。
- 批量任务可取消，取消后不再启动新的请求；完成后显示成功、失败、跳过数量。
- 目标歌曲已在收藏中或多首误匹配到同一目标时不得产生重复项。
- 正常完成时将所有成功项作为一次歌单写入提交，失败项保留原记录；用户主动
  取消时丢弃本批已找到的候选，不修改收藏。

## Acceptance Criteria

- [ ] 用户可从收藏页进入换源模式并勾选/全选歌曲。
- [ ] 目标音源选择只展示当前可搜索单曲的已启用插件。
- [ ] 同名不同歌手、翻唱、现场版、无结果及不可播放候选不会被静默误替换。
- [ ] 成功替换项重新进入收藏页后仍为目标源，原顺序不变。
- [ ] 未选中、匹配失败、验证失败、重复和取消后的条目保持原记录。
- [ ] 批量处理不会阻塞 UI，结束后提供可理解的结果摘要。

## Out Of Scope

- 不在播放失败时自动永久改写收藏；现有临时自动换源开关保持独立。
- 不处理本地音乐、播放历史或远程插件歌单。
- 不跨多个目标插件自动挑选来源；每次批量操作由用户指定一个目标插件。
