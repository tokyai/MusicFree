# 修复搜索与双向换源并增加局域网备份

## Goal

让播放详情中的作者/专辑入口可靠地进入“已填关键词且已经有结果”的搜索页；让收藏批量换源在两个来源之间都能工作，并以用户可接受的曲名和歌手匹配为准；在车机文件选择器不可用时，提供手机浏览器可参与的局域网备份与还原。

## Background And Confirmed Facts

- 目标代码库是 `D:\Sync\Tianyi\MusicFree`，当前基线为 `e795669`，本任务不修改其他 MusicFree 工作区。
- 作者/专辑入口位于 `src/components/panels/types/musicItemOptions.tsx:89-115`，通过 `navigate(SEARCH_PAGE, { initialQuery })` 进入搜索页。
- 搜索页 `src/pages/searchPage/index.tsx:37-54` 只在首次挂载或 `initialQuery` 字符串变化时触发搜索；React Navigation 复用已有路由时不会保证再次执行该逻辑。
- 批量换源服务位于 `src/core/musicSourceSwitcher.ts:149-286`；当前匹配器 `src/utils/musicSourceMatch.ts:176-264` 还会硬性要求时长兼容、版本标签相同和严格阈值。
- 换源提交由 `MusicSheet.replaceMusicItems` 完成，`platform@id` 仅用于目标去重，不代表跨平台歌曲相同。
- 当前完整备份入口是 `Backup.backup()` / `Backup.resume()`（`src/core/backup.ts:29-99`），FTP 已有 Android 原生桥；文件选择器相关流程在车机上不可用。
- Android 最低版本为 API 24（`android/build.gradle:4`）。

## Requirements

### R1. 作者/专辑直达搜索

- 点击作者或专辑后必须进入新的或重新聚焦的搜索页。
- 搜索框填入对应文本后自动发起音乐搜索，不要求用户再次点击“搜索”。
- 即使目标文本与上一次相同，也必须重新发起搜索；已有搜索页、返回再进入、快速连续点击都不能留下旧结果或只显示编辑状态。
- 保留手动搜索、搜索历史和其他入口的现有行为。

### R2. 双向批量换源

- 收藏编辑器中选择任意目标插件时，源插件为轻 QQ 或轻酷狗的歌曲均可向另一方向迁移。
- 主匹配条件为规范化后的曲名和歌手相同/高度相似；忽略平台 ID 差异，不把专辑或时长差异直接判为失败。
- 专辑、时长、版本标记可以作为候选排序的辅助信息，但不能阻止同曲名同歌手的可播放候选。
- 仍须验证候选可播放、避免目标平台重复键，并保留原歌曲位置、`$timestamp` 和 `$sortIndex`。
- 目标搜索无结果、候选不可播放、输入损坏、取消和持久化失败要保持现有可见错误/失败统计语义。
- 不把临时取流 URL 或解析缓存写入收藏项；不改变未选中的歌曲。

### R3. 局域网备份

- 在备份与恢复设置中增加局域网备份入口，备份内容与 `Backup.backup()` 完全一致（歌单和插件配置）。
- 车机端点击“局域网备份”后启动一次性临时 HTTP 服务，显示局域网访问地址、复制入口和等待状态；手机浏览器访问后可以下载 JSON 备份。
- 车机端点击“局域网还原”后启动一次性临时 HTTP 服务，手机浏览器可以选择并上传 JSON 备份；上传完成后车机调用现有 `Backup.resume(raw, resumeMode)`。
- 服务只监听局域网接口，使用随机短时令牌，单次传输完成或取消/超时后自动关闭；不能长期驻留或暴露无令牌的备份数据。
- 传输失败、格式非法、超过大小限制、用户取消和平台不支持时显示可理解的提示，并清理线程、套接字和临时数据。
- Android API 24 及以上可用；非 Android 平台通过能力标记禁用入口，不影响 FTP/WebDAV/URL 方式。

## Acceptance Criteria

- [ ] 从播放详情点击作者，搜索页立即显示该作者的音乐结果；点击专辑同理；重复点击相同作者/专辑仍会重新搜索。
- [ ] 从已有搜索页、返回后再次进入、横竖屏切换后执行上述入口，搜索状态和结果均正确，无需手动提交。
- [ ] 自动化回归测试覆盖搜索页重复请求/聚焦行为，且不破坏手动搜索。
- [ ] 换源测试覆盖轻 QQ -> 轻酷狗和轻酷狗 -> 轻 QQ 两个方向，并覆盖时长不同、专辑不同但曲名和歌手相同的候选；两方向都产生可播放替换。
- [ ] 换源测试覆盖目标重复键、取消、无结果和不可播放候选；未选歌曲和原位置保持不变。
- [ ] Android 原生桥测试/编译通过：服务启动返回可访问 URL，上传/下载各完成一次后自动关闭，取消和超时释放资源，非法请求不会解析恢复。
- [ ] 设置页可从局域网入口完成一次备份下载和一次还原上传；还原失败不会修改现有歌单。
- [ ] `npx tsc --noEmit`、聚焦 Jest 测试、`npx eslint src --ext .js,.jsx,.ts,.tsx` 和 `android\gradlew.bat :app:compileDebugKotlin` 通过。

## Out Of Scope

- 不实现旧版 MusicFree 收藏迁移或跨应用数据库读取。
- 不增加手机配套 App、云端账号、二维码扫描服务或 FTP 协议改造；局域网端以手机浏览器和车机临时 HTTP 服务为边界。
- 不改变现有 FTP、FTPS、WebDAV、URL 备份协议及文件选择器之外的页面。
- 不把“同名同歌手”扩展为自动合并重复收藏；目标键冲突仍按跳过处理。

## Risks And Deferred Items

- 某些插件可能返回缺少歌手字段的结果；此类候选仍应报告失败而不是猜测匹配。
- 局域网发现依赖手机和车机处于同一可互通网段；界面需明确提示关闭 AP 隔离或改用地址复制，但不增加局域网扫描协议。
- HTTP 服务使用明文局域网传输，随机令牌和一次性生命周期只能降低暴露面，不能替代 HTTPS；界面需显示“仅限可信局域网”的提示。
