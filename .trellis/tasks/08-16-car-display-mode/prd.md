# 车机显示模式适配

## Goal

在不改变现有手机默认显示的前提下，提供一个可手动开启的车机显示模式，让横屏车机在较远观看距离下仍具有清晰字体、足够点击区域和合适的侧栏/浮层宽度。

## Background

- 当前横屏页面已使用 `ResponsiveSplitView`，常规页面默认 `38:62`，播放详情为 `50:50`；本任务不重做该结构。
- 当前字体和多数控件由 `rpx()` 按启动时的逻辑短边缩放。逻辑短边为 360dp 时，描述、正文和标题约为 10.6dp、13.4dp、15.4dp，车机远距离观看偏小。
- 目标车机为 1920×1080、14.6 英寸（约 150.9 PPI、16:9）；物理分辨率不会直接等于 React Native 的逻辑 dp，实际短边仍以运行时窗口尺寸为准。
- `ThemeText` 固定关闭系统字体缩放，不能依赖车机系统设置补偿字号。
- `LandscapeNavigationRail`、AppBar 和部分 Chip/小列表项在低逻辑短边设备上的点击高度可能低于 48dp。
- AppConfig 已提供 typed MMKV 持久化、React 订阅和设置页开关模式，可以作为唯一配置所有者。

## Requirements

### R1. Explicit mode and compatibility

- 在基本设置中增加“车机显示模式”开关，默认关闭。
- 在该开关旁增加独立的“车机字号档位”选择，至少提供“适中”和“大字”两档；用户可随时切换，切换后立即作用于车机显示规格。
- 新安装、升级后尚未写入配置时使用“关闭 + 适中”；关闭车机模式不会清除上次选择的字号档位。
- 关闭时字体、控件、面板和页面结构与当前版本保持一致。
- 开启时应用统一的车机显示规格；不根据品牌、物理分辨率或屏幕比例自动开启。
- 对该 14.6 英寸车机，推荐先使用“适中”档；若实际观看距离较远或仍觉得偏小，再切换“大字”，不自动根据物理尺寸切档。
- 配置继续由 AppConfig 持久化，不增加第二套存储或平台专用业务状态。

### R2. Typography

- 车机模式为标签、描述、副标题、正文、标题和 AppBar 字体提供明确的逻辑 dp 下限。
- 播放详情歌词的四档选择继续有效，车机模式只提高各档下限，不覆盖用户已经选择的档位。
- 文本放大后，标题、歌手、专辑、来源、设置项和操作按钮不得互相覆盖；需要截断的单行文本继续使用现有省略语义。
- 手机模式继续保持当前 `rpx()` 字号和现有 `allowFontScaling` 行为。

车机模式的逻辑 dp 下限如下；实际值取当前 `rpx()` 基准与所选下限中的较大值，因此不会缩小高逻辑短边设备原有字号。

| 档位 | 标签 | 描述 | 副标题 | 正文 | 标题 | AppBar |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 适中 | 14 | 16 | 18 | 18 | 22 | 24 |
| 大字 | 16 | 18 | 20 | 20 | 24 | 28 |

播放详情歌词继续保留“小、标准、大、超大”四档，车机模式仅分别应用以下下限：

| 车机档位 | 小 | 标准 | 大 | 超大 |
| --- | ---: | ---: | ---: | ---: |
| 适中 | 18 | 20 | 22 | 24 |
| 大字 | 20 | 22 | 24 | 28 |

### R3. Touch targets and controls

- 车机模式下所有主要可点击列表行、导航项、图标按钮、Chip 和确认操作满足统一的最小点击高度。
- 图标与容器同步放大，但不通过逐页面复制尺寸实现。
- 歌曲行仍保持有序表格结构，放大后不得隐藏标题和操作列。
- “适中”和“大字”的主要点击区域最小高度分别为 56dp 和 64dp；不可见的 hitSlop 可以补足触摸范围，但可见容器仍应容纳放大后的文字和图标。

### R4. Wide-screen overlays

- 保留主页面 `38:62` 和播放详情 `50:50` 分栏。
- 普通 Panel、抽屉和 Dialog 在车机模式下依据实际可用宽度设置合理上限，不继续只以短边作为唯一宽度。
- 全屏 Panel 仍保持全屏；返回键、遮罩关闭、键盘避让和动画行为不变。

### R5. Scope and safety

- 只调整共享 React Native 显示层和 typed config/i18n，不修改播放、歌词匹配、B站识曲、插件、下载或音源请求逻辑。
- Android 基线继续为 API 24+，不增加运行时依赖。
- 尺寸计算应随窗口变化更新，支持车机系统栏和可调整窗口，不在每个列表项注册 Dimensions 监听器。

## Out of Scope

- 自动识别车机、Android Auto/Android Automotive 专用入口或驾驶状态限制。
- 语音控制、方向盘按键、焦点导航、横竖屏锁定和车厂定制接口。
- 重做主题、导航架构、播放器功能或手机默认字号。

## Acceptance Criteria

- [ ] AC1: 新安装或升级后车机模式默认关闭，并存在可持久化的字号档位选择；关闭时现有手机横竖屏尺寸没有有意变化。
- [ ] AC2: 开启后，逻辑短边 360dp、480dp、600dp 三档下的共享字体均不低于选定的车机字号下限。
- [ ] AC3: 开启后，主要导航、列表、Chip、图标按钮和确认操作达到选定的最小点击高度。
- [ ] AC4: 主页、播放详情、搜索、榜单、歌单/专辑详情、设置、编辑器和文件选择器无字体重叠、操作裁切或不可恢复空白。
- [ ] AC5: 歌曲表格行仍展示标题和操作列；窄右窗格按既有 compact 规则隐藏次要列。
- [ ] AC6: 普通 Panel、抽屉和 Dialog 在超宽车机上不过窄、不越过安全区；全屏 Panel 行为不变。
- [ ] AC7: 开关和窗口尺寸变化实时生效，不中断播放、不重置请求或选择状态、不为列表行增加尺寸监听器。
- [ ] AC8: TypeScript、Jest、ESLint 零错误；Android debug 构建通过。
- [ ] AC9: 在至少一档 360–480dp 逻辑短边和一档 600dp 以上逻辑短边完成横屏截图与点击验证。
